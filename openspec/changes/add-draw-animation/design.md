# 设计说明（Design）

## 组件结构
- drawAnimation 组件：独立于业务逻辑，负责动画渲染与交互反馈。
- 支持属性：template（模板配置）、autoStart（自动开始）。
- 事件：onDrawStart（动画请求抽签）、onDrawComplete（动画结束回调）。

## 动画流程
1. 用户点击竹筒或自动开始，进入摇晃动画。
2. 动画中途触发 onDrawStart，父页面执行抽签逻辑。
3. 父页面通过 showResult 方法传递抽签结果，组件播放签条飞出与结果展示动画。
4. 动画结束后触发 onDrawComplete，父页面落盘数据并提示。

## 页面集成
- result 页面集成 drawAnimation 组件，绑定事件驱动抽签与结果展示。
- 兼容无动画模式，保证功能完整性。

## 交互与体验
- 粒子特效、震动反馈、音效增强沉浸感。
- 动画阶段分明，提示文案友好。

## 可扩展性
- 组件参数化，便于后续支持更多动画风格或模板。
